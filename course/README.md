# Instructor Course Pack

This folder contains cross-module teaching assets.

## Included

- `syllabus.md`: course-level schedule and outcomes
- `schedule-6-week-cohort.md`: session-by-session plan for a 6-week cohort
- `architecture/`: reference architectures and “what-good-looks-like”
- `checklists/`: readiness checklists and grading templates
