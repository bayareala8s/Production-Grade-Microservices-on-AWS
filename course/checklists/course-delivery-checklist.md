# Course Delivery Checklist (Instructor)

## Before the course

- Confirm student prerequisites (AWS account, CLI, Docker, Python/Node/Java as chosen).
- Provide starter repos ZIP (or this repo) and verify labs run locally.
- Provide environment setup guide and a “known issues” doc.

## Before each module

- Review module learning outcomes and checkpoints.
- Pre-run labs end-to-end once (timebox and record expected outputs).
- Prepare slides or a whiteboard outline using the module’s `course-outline.md`.

## During labs

- Enforce “contract discipline”: shape + versioning + standard errors.
- Require a short demo from each student/team at end of module.
- Capture common mistakes and add them to the module’s instructor notes.

## After each module

- Collect feedback: confusion points, time overruns, tooling friction.
- Update rubrics and checkpoints for clarity.
