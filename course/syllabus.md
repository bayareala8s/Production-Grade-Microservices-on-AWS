# Course Syllabus — Production-Grade Microservices on AWS (BayAreaLa8s)

## Target audience

Software engineers with basic Docker and AWS familiarity who want to learn **how microservices are built and operated in production**.

## Learning outcomes (course-level)

Students will be able to:

- decompose systems into bounded contexts and service ownership
- design stable API contracts (versioning, validation, error contracts)
- choose and operate compute platforms (ECS Fargate/EKS/Lambda)
- build resilient service networking (timeouts/retries, gateways, internal calls)
- manage data across services (idempotency, eventual consistency, saga intro)
- apply least-privilege security (IAM roles, secrets, network isolation)
- operate in production (logs/metrics/traces, SLIs/SLOs, canaries)
- ship safely (CI/CD, blue/green deployments, rollback strategies)
- deliver a capstone platform with architecture, CI/CD, and observability

## Suggested schedule (9 modules)

- Module 1: Microservices foundations (enterprise reality)
- Module 2: Building production APIs
- Module 3: Containers & AWS compute choices
- Module 4: Service networking & traffic management
- Module 5: Data, state & consistency
- Module 6: Security & identity
- Module 7: Observability, testing & reliability
- Module 8: CI/CD & zero-downtime deployments
- Module 9: Capstone — production microservices platform

## 6-week cohort schedule

See `course/schedule-6-week-cohort.md` for a session-by-session plan (2 live sessions/week) with homework and capstone milestones.

## Grading approach (recommended)

- 40% labs completion (functional + meets rubric)
- 30% capstone architecture + implementation quality
- 20% operability (observability, runbooks, failure handling)
- 10% communication (design docs, demo clarity)
