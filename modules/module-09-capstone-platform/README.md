# Module 9 — Capstone: Production Microservices Platform

## Goal

Students deliver a **resume-grade, production-style** microservices platform:

- multiple services with clear ownership boundaries
- versioned APIs and/or event-driven integration
- deployment pipelines
- observability dashboards
- runbooks and demo walkthrough

## Capstone options (pick one)

1. E-commerce backend: Orders, Payments, Inventory
2. Internal platform APIs: Service Catalog, Access Requests, Audit Logs
3. Event-driven system: Ingestion → processing → notification
4. SaaS backend: Auth, Billing, Usage, Admin
