# Capstone Milestones (Suggested)

## Milestone 1 — Design (Day 1)

- service boundaries and ownership table
- API/event contracts drafted
- initial threat model (Module 6)
- initial SLO proposal (Module 7)

## Milestone 2 — Vertical slice (Day 2)

- one end-to-end flow implemented across services
- containerized services
- basic logging + health endpoints

## Milestone 3 — Production hardening (Day 3)

- idempotency strategy (Module 5)
- retries/timeouts and failure handling (Module 4)
- basic dashboards and alarms (Module 7)

## Milestone 4 — Delivery (Final)

- CI pipeline(s) (Module 8)
- deployment strategy documented (rolling or blue/green)
- runbooks completed
- demo walkthrough rehearsed
