# Module 5 — Data, State & Consistency

## Goal

Teach students to handle data safely across microservices:

- database-per-service
- eventual consistency via events
- idempotency keys
- saga patterns (intro)

## Outcomes

Students can:

- design data ownership boundaries
- implement idempotent handlers conceptually (and in code later)
- model an event-driven consistency workflow using EventBridge

## Included in this module

- `course-outline.md`: timeboxed lesson plan + checkpoints
- `labs/`: step-by-step labs (design + implementation patterns)
- `instructor-guide.md`: coaching notes + common pitfalls
- `grading-rubric.md`: scoring suggestions
- `starter/` (optional): lightweight artifacts (event schemas, example payloads)

## Prerequisites

- Completion of Modules 1–4 (recommended)
- Basic familiarity with HTTP APIs and asynchronous messaging concepts
