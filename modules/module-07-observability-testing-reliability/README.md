# Module 7 — Observability, Testing & Reliability

## Goal

Operate microservices in production with:

- logs, metrics, traces
- health checks and runbooks
- SLIs/SLOs and error budgets
- reliability testing (smoke, canary, synthetic checks)

## Outcomes

Students can:

- instrument services with structured logs and correlation IDs
- build dashboards and alarms that map to customer experience
- trace requests across services (distributed tracing)
- define SLIs/SLOs and validate systems with canary/smoke tests
