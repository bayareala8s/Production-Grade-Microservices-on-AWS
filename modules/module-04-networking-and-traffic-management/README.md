# Module 4 — Service Networking & Traffic Management

## Goal

Teach students how traffic flows in production microservices:

- external entrypoints (API Gateway vs ALB)
- internal service-to-service communication
- timeouts, retries, circuit breakers (conceptually)
- resilience through sane defaults and failure-aware design

## Outcomes

Students can:

- choose API Gateway vs ALB based on use case
- configure timeouts/retries at the right layers
- simulate a failure and explain blast radius
