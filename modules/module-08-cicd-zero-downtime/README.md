# Module 8 — CI/CD & Zero-Downtime Deployments

## Goal

Ship microservices safely and repeatedly with:

- CI pipelines (build, test, scan)
- environment promotion
- rolling and blue/green deployments
- automated rollback on failures

## Outcomes

Students can:

- design a CI pipeline per service
- implement deployment strategies appropriate for ECS
- define release gates using metrics/alarms
- create rollback strategies that are automated and testable
