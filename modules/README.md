# Course Modules — Production-Grade Microservices on AWS

This folder contains one **teach-ready module** per topic area.

## Conventions used across modules

Each module generally includes:

- `README.md`: goals, prerequisites, outcomes, and how to run labs
- `course-outline.md`: lesson plan, timing, slides outline, checkpoints
- `labs/`: step-by-step lab guides
- `instructor-guide.md`: coaching notes and pitfalls
- `grading-rubric.md`: suggested scoring rubric
- `starter/` (optional): starter code and/or IaC templates used by the labs
