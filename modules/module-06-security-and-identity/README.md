# Module 6 — Security & Identity

## Goal

Secure microservices like an enterprise:

- IAM roles per service (least privilege)
- JWT/OAuth concepts and practical API auth
- secrets management (Secrets Manager / Parameter Store)
- network isolation (VPC, subnets, security groups)

## Outcomes

Students can:

- design and apply least-privilege IAM policies for services
- implement authenticated API flows and understand token validation
- store and rotate secrets without hardcoding
- isolate services in private networks and control ingress/egress
