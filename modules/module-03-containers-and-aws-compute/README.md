# Module 3 — Containers & AWS Compute Choices

## Goal

Students learn to:

- containerize microservices like production teams
- choose ECS Fargate vs EKS vs Lambda based on constraints
- deploy a containerized API to **ECS Fargate** with basic scaling

## Outcomes

Students can:

- write a production-friendly Dockerfile
- explain compute tradeoffs (ops overhead, latency, scaling, cost)
- run a microservice on ECS Fargate (task definition + service)
